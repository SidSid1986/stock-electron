tcp-demo 项目介绍

启动项目,如果有白屏问题，ctrl+c 退出项目，在启动即可。打包不会有这个问题

```
npm run electron:serve
```

打包项目

```
npm run electron:build:win
```

打包后的文件

```
electron_dist/win-unpacked/Tcp.exe
```
